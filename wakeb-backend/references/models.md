# Models Reference

## BaseModel

All models extend `BaseModel` which defines permission metadata:

```php
abstract class BaseModel extends Model
{
    // Whether this model is registered in the permission system
    public bool $inPermission = false;

    // Standard CRUD operations: auto-creates "create-{model}", "update-{model}", "delete-{model}"
    public array $basicOperations = ['create', 'update', 'delete'];

    // Extra operations: "view-all-{model}", "view-own-{model}", "force-delete-{model}", etc.
    public array $specialOperations = ['view-all', 'view-own', 'force-delete', 'restore', 'toggle-active'];
}
```

Permission names are auto-generated by `PermissionSeeder`:

- `$basicOperations` → e.g., `create-country`, `update-country`, `delete-country`
- `$specialOperations` → e.g., `view-all-country`, `force-delete-country`, `toggle-active-country`

## Essential Traits

### HasTranslations (Spatie)

Stores multi-language data in JSON columns:

```php
class Country extends BaseModel
{
    use HasTranslations;
    public array $translatable = ['name', 'description'];
}

// Usage
$country->name;                      // Returns name in current locale
$country->getTranslation('name', 'ar'); // Returns Arabic name
$country->getTranslations('name');   // Returns ['ar' => '...', 'en' => '...']
$country->setTranslation('name', 'en', 'Egypt');
```

### SoftDeletes

Standard Laravel soft deletes. Always include `$table->softDeletes()` in migration.

```php
class Country extends BaseModel
{
    use SoftDeletes;
}

// Queries
Country::withTrashed()->get();       // Include soft-deleted
Country::onlyTrashed()->get();       // Only soft-deleted
$country->trashed();                 // Check if soft-deleted
$country->restore();                 // Restore
$country->forceDelete();             // Permanently delete
```

### CreatedByObserver

Auto-sets `created_by` from the authenticated user on model creation:

```php
class Country extends BaseModel
{
    use CreatedByObserver;
    // Requires: $fillable must include 'created_by'
    // Requires: migration must have created_by FK
}
```

### LogsActivityOptions

Configures Spatie Activity Log:

```php
class Country extends BaseModel
{
    use LogsActivityOptions;

    public function getActivitylogOptions(): LogOptions
    {
        return LogOptions::defaults()
            ->logOnlyDirty()
            ->logOnly($this->fillable);
    }
}
```

### ApplyNotification

Adds notification support to models:

```php
class FormEntry extends BaseModel
{
    use ApplyNotification;

    // Usage in controller after create/update:
    $entry->sendNotification(
        ['user_ids' => [1, 2, 3], 'title' => '...', 'body' => '...'],
        ['email', 'realtime', 'notify', 'sms']
    );
}
```

Channels:

- `email` → dispatches `SendEmailJob`
- `sms` → dispatches `SendSMSJob`
- `realtime` → broadcasts via Laravel Echo / Reverb
- `notify` → stores in database notifications

## Common Model Structure

```php
<?php

namespace App\Models;

use App\Trait\Global\CreatedByObserver;
use App\Trait\Global\LogsActivityOptions;
use Illuminate\Database\Eloquent\Casts\Attribute;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Database\Eloquent\Relations\HasMany;
use Illuminate\Database\Eloquent\SoftDeletes;
use Spatie\Activitylog\LogOptions;
use Spatie\Translatable\HasTranslations;

class Product extends BaseModel
{
    use HasTranslations, SoftDeletes, CreatedByObserver, LogsActivityOptions;

    public array $translatable = ['name', 'description'];
    public bool $inPermission = true;
    public array $basicOperations = ['create', 'update', 'delete'];
    public array $specialOperations = ['view-all', 'view-own', 'force-delete', 'restore', 'toggle-active'];

    protected $fillable = [
        'name',
        'description',
        'code',
        'price',
        'image',
        'is_active',
        'category_id',
        'created_by',
    ];

    protected $casts = [
        'is_active' => 'boolean',
        'price'     => 'decimal:2',
    ];

    /*
    |--------------------------------------------------------------------------
    | Activity logs
    |--------------------------------------------------------------------------
    */
    public function getActivitylogOptions(): LogOptions
    {
        return LogOptions::defaults()->logOnlyDirty()->logOnly($this->fillable);
    }

    /*
    |--------------------------------------------------------------------------
    | Accessors / Mutators
    |--------------------------------------------------------------------------
    */
    public function image(): Attribute
    {
        return Attribute::make(
            get: fn($value) => $value ? Media::url($value) : null,
        );
    }

    /*
    |--------------------------------------------------------------------------
    | Relations
    |--------------------------------------------------------------------------
    */
    public function creator(): BelongsTo
    {
        return $this->belongsTo(User::class, 'created_by');
    }

    public function category(): BelongsTo
    {
        return $this->belongsTo(Category::class);
    }

    public function items(): HasMany
    {
        return $this->hasMany(ProductItem::class);
    }

    /*
    |--------------------------------------------------------------------------
    | Scopes
    |--------------------------------------------------------------------------
    */
    public function scopeActive($query)
    {
        return $query->where('is_active', true);
    }

    public function scopeByCategory($query, $categoryId)
    {
        return $query->where('category_id', $categoryId);
    }
}
```

## User Model (extended)

The User model has additional traits and complexity:

```php
class User extends Authenticatable
{
    use HasApiTokens, HasRoles, HasFactory, Notifiable;
    use HasTranslations, SoftDeletes, CreatedByObserver, LogsActivityOptions;

    public bool $inPermission = true;
    public array $translatable = ['name'];

    protected $hidden = ['password', 'remember_token'];

    protected $casts = [
        'email_verified_at' => 'datetime',
        'password'          => 'hashed',
        'is_active'         => 'boolean',
    ];

    // Phone accessor: always returns digits-only
    public function phone(): Attribute
    {
        return Attribute::make(
            get: fn($value) => $value ? preg_replace('/\D/', '', $value) : null,
        );
    }
}
```

## Model Conventions Summary

| Convention    | Rule                                                     |
| ------------- | -------------------------------------------------------- |
| Base class    | `extends BaseModel` (always)                             |
| Permissions   | Set `$inPermission = true` if model has CRUD permissions |
| Soft deletes  | Always use `SoftDeletes` trait                           |
| Audit         | Always use `CreatedByObserver` + `LogsActivityOptions`   |
| Translatable  | `$translatable` array + JSON column in migration         |
| Fillable      | Explicit `$fillable` (never use `$guarded = []`)         |
| Casts         | Cast booleans, decimals, dates explicitly                |
| Relations     | Use proper return types (`BelongsTo`, `HasMany`, etc.)   |
| Section order | Activity logs → Accessors → Relations → Scopes           |
